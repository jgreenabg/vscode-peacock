# Peacock for Visual Studio Code

Color your VS Code or Cursor workspace so you can tell open editors apart. Useful with multiple windows or Remote sessions.

![Peacock Hero](assets/hero.png)

## Features

- Identify each editor instance with a favorite color
- Apply a distinct color in Remote workspaces

## Quick start

1. Install Peacock from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=johnpapa.vscode-peacock)
1. Open the command palette (`Ctrl+Shift+P` / `Cmd+Shift+P`)
1. Run **Peacock: Change to a Favorite Color**
1. Pick a color
