# About Peacock

Color your VS Code or Cursor workspace so you can tell open editors apart. Useful with multiple windows or Remote sessions.

## Why Peacock

Switching between several VS Code windows is slow when they all look the same. Peacock colors key chrome so you can spot the right instance fast — useful for coding, writing, and demos.

## History

[Winter is Coming](https://marketplace.visualstudio.com/items?itemName=johnpapa.winteriscoming&wt.mc_id=vscodepeacock-github-jopapa) taught how VS Code theming works. That led to automating workspace color differentiation instead of changing colors by hand.

After a working prototype, a gif on Twitter drew strong interest and early contributions. Install Peacock from the [marketplace](https://marketplace.visualstudio.com/items?itemName=johnpapa.vscode-peacock&wt.mc_id=vscodepeacock-github-jopapa).
